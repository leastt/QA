# Doodle icon variants

48 doodle variants are provided alongside the current accounting icons. Each new filename uses English words or brand names and the `_doodle` suffix. Existing filenames and `CITICiPlatinum.png` are unchanged.

The artwork is restored byte-for-byte from commit [`df97957`](https://github.com/leastt/QA/commit/df97957). PNG/JPEG formats, 1024 x 1024 dimensions, and in-image labels are preserved. Currency suffixes follow the original filenames; the older artwork may display the original HK/US region abbreviations. The English naming requirement applies to filenames, so existing Chinese brand lettering inside the artwork is retained.
